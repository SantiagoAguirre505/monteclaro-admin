# Monte Claro Admin

Aplicación de administración para un aserradero, desarrollada en .NET MAUI para funcionar en PC, tablet y celular.

## Requisitos
- Visual Studio 2022
- .NET 8 SDK
- MAUI workloads instalados

## Cómo probarla
1. Clona el repositorio.
2. Abre `MonteClaroAdmin.sln` con Visual Studio.
3. Selecciona un emulador o dispositivo Windows.
4. Compila y ejecuta.

## Descripción
- Dashboard visual con resumen del día
- Inventario de productos
- Control de recepciones
- Seguimiento de ventas
- Vista de empleados
- Diseño inspirado en el aserradero mostrado en la referencia

## Conexión con Replit
Los datos actuales son mockdata para que puedas probar ui y flujo. Luego puedes reemplazar `MockDataService` por llamadas HTTP a tu backend en Replit.
